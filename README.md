# Netflix-content-analysis
Exploratory data analysis of Netflix content with data visualization and business insights
## Tasks

- Data exploration and preprocessing
- Exploratory Data Analysis (EDA)
- Analysis of content characteristics and distributions
- Data visualization
- Identification and interpretation of patterns in the data
- Formulation of business-oriented insights and recommendations
## Key Outcomes

The analysis helped identify patterns in the Netflix content catalog and demonstrate how exploratory data analysis can be used not only to describe data, but also to support business decisions.

The final stage of the project included interpretation of the findings and preparation of recommendations for a hypothetical business stakeholder.
